# Edit Flow

> 一体化媒体作品发布工作流系统 for Obsidian

可自定义的一体化媒体作品发布工作流系统 —— 从灵感、选题、脚本、文案、封面、作品到发布，全流程管理。专为内容创作者（视频/图片/文字）设计，深度集成 Obsidian。

## 特性

### 全流程管理
- **七大阶段**：灵感 → 选题 → 脚本 → 文案 → 封面 → 作品 → 发布
- **看板视图**：按分类分组展示作品，已发布作品自动折叠
- **导航视图**：作品列表 + 搜索 + 分类筛选 + 作品对象筛选
- **日历视图**：按周/月查看发布排期和作品状态

### 全自定义
- **作品类型**：主分类（图标/颜色）+ 子类（图标/颜色/模板），全部可自定义增删改
- **作品对象**：目标受众/创作对象（如粉丝/客户/自己），支持自定义，可按对象筛选作品
- **模板系统**：每个子类有独立模板文件（`EF-xxx.md`），可直接在 Obsidian 里编辑
- **文件夹结构**：作品/脚本/素材库/便签/模板/灵感文件夹位置均可自定义
- **账号管理**：发布平台账号自定义（小红书/抖音/B站等）

### 原生 Obsidian 集成
- **便签 md 化**：便签数据保存为 Obsidian md 文件（frontmatter 存元数据），不依赖 data.json
- **逻辑线**：每个作品自动生成逻辑线脚本，侧边栏节点编辑（标题/内容/备注/手写画板）
- **作品索引双向同步**：workIndex 与文件 frontmatter 自动同步
- **标准设置页**：使用 Obsidian 原生 PluginSettingTab
- **全局搜索**：可全局搜索带有“灵感/作品”标签的内容

### 移动端兼容
- 触摸优化：按钮最小 32px 触摸区，input/textarea 16px 字号防缩放
- 逻辑线节点上下移动按钮（替代拖拽排序）
- 看板单列布局，Modal 全屏化
- 手写画板支持触摸绘制

### 视觉设计
- 莫兰迪色系（8 色）统一配色
- 53 图标库可选
- 贴合 Obsidian 原生主题变量

## 安装

### 手动安装
1. 下载 `main.js`、`styles.css`、`manifest.json` 三个文件
2. 在 Obsidian 库的 `.obsidian/plugins/` 下创建 `edit-flow` 文件夹
3. 把三个文件放进去
4. 设置 → 第三方插件 → 关闭安全模式 → 启用 "Edit Flow"

### BRAT（推荐测试用）
可通过 [BRAT 插件](https://github.com/TfTHacker/obsidian42-brat) 安装测试版本。

## 使用

### 首次使用
1. 启用插件后，根目录会自动创建文件夹结构（作品/脚本/素材库/便签/模板/灵感）
2. 设置 → Edit Flow → 作品类型 → 添加主分类（如"视频作品"）和子类（如"短视频"）
3. 可选：添加作品对象（如"粉丝"）、发布平台账号
4. 点左侧栏图标打开看板/导航，开始创建作品

### 创建作品
- 看板页或导航页点"新建作品"
- 选择主分类、子类、起始阶段、作品对象（可选）
- 自动生成作品文件 + 逻辑线脚本
- 所有作品都支持逻辑线（不强制时间格式，按顺序编号）

### 自定义模板
- 模板文件夹下每个子类对应一个 `EF-{子类名}.md`
- 直接在 Obsidian 编辑这些文件即可自定义模板
- 支持变量：`{{title}}`（作品标题）、`{{date}}`（当天日期）
- 设置页有"刷新模板"按钮可重置为内置默认模板

### 作品对象筛选
- 导航页"作品对象"区域，点击 chip 筛选该对象下的作品
- 作品列表每行显示对象标签，点击标签可快速切换筛选

## 文件结构

```
根目录/
├── 作品/           # 所有作品文件
├── 脚本/           # 逻辑线脚本
├── 素材库/         # 素材文件（递归读取）
├── 便签/           # 便签 md 文件
├── 模板/           # 作品模板（EF-xxx.md）
└── 灵感/           # 灵感笔记
```

## 技术细节

- **数据存储**：作品索引存 `data.json`，便签存 md 文件，作品元数据存 frontmatter
- **双向同步**：workIndex ↔ 文件 frontmatter，vault 事件监听自动同步
- **兼容性**：支持桌面端和移动端，最低 Obsidian 1.4.0
